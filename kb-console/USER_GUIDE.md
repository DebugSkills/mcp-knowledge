# 🖥️ MCP Knowledge Console — руководство пользователя

**kb-console** — веб-интерфейс для проверки и обслуживания MCP Knowledge Server: статус системы, загрузка материалов, поиск по базе знаний. Открывается в браузере на порту **8085**.

## 🚀 Запуск

**На серверном хосте** (вместе с сервером — уже настроено в compose):
```bash
docker compose up -d            # dev
# или из air-gap bundle:
./scripts/offline-deploy.sh deploy
```
→ открыть `http://localhost:8085`

**На клиентском хосте** (отдельно от сервера):
```bash
docker run -d --name kb-console \
  -e MCP_SERVER_URL=http://<server-ip>:8000 \
  -e MCP_API_KEY=<ключ из .env сервера> \
  -p 8085:8085 kb-console:prod
```
→ открыть `http://localhost:8085`

## 📑 Страницы

### 1. Статус
Проверка «всё ли работает»:
- **Карточки компонентов** — сервер, Qdrant, Embedding, Pipeline, DLQ: ✅ зелёное = ок, ❌ красное = проблема (с деталями).
- **Метрики** — очередь, ошибки, размер коллекции, аптайм.
- **Инструменты** — все 18 MCP-инструментов, доступных для вызова.
- Страница обновляется автоматически каждые 10 секунд (кнопка «Обновить» — вручную).

### 2. Импорт
Загрузка материалов в базу знаний:
1. Вставьте текст (Markdown) в поле.
2. Заполните: **тип контента** (`book`), **домен**, **предмет** (обязательные), теги (опционально).
3. Нажмите **«Импортировать»**.
4. Внизу — результат: `imported` (добавлено), `failed` (ошибки с номерами разделов и причинами).

### 3. Поиск
Пробная проверка поиска по корпусу:
1. Введите запрос (естественным языком), при необходимости `top_k`.
2. Нажмите **«Найти»** → таблица результатов: заголовок, score, домен, предмет.

## ⚠️ Частые проблемы

| Симптом | Причина / решение |
|---|---|
| «Сервер недоступен» | MCP_SERVER_URL указывает не туда; сервер не запущен (`docker ps`). |
| «Ошибка авторизации» | MCP_API_KEY не задан или не входит в ключи сервера (для импорта нужен ключ с правами записи). |
| Импорт: 0 добавлено | Проверьте domain/subject — обязательные поля; разделы с ошибками перечислены в `failed_sections`. |
| Красные карточки в Статусе | Смотрите деталь в карточке; `/health` сервера отдаёт причину (например, Qdrant недоступен). |

## 🔧 Конфигурация (env)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `MCP_SERVER_URL` | `http://localhost:8000` | Адрес MCP-сервера (на клиентском хосте — IP сервера) |
| `MCP_API_KEY` | пусто | Ключ доступа (если на сервере включена авторизация) |
| `CONSOLE_PORT` | `8085` | Порт веб-интерфейса |
| `REFRESH_SECONDS` | `10` | Интервал автообновления страницы «Статус» |
